MCP server

Ask your assistant, get a sourced number

The Model Context Protocol (MCP) is an open standard that lets an AI assistant call tools a server exposes. Lead Green ships a small MCP server so that Claude, Cursor or any MCP-capable client can answer questions about the index with the row, the source and the caveat attached, instead of guessing.

Package leadgreen-mcp {{MCP_VERSION}} · Transport stdio · Data the live API, with a bundled snapshot as fallback · Licence Apache 2.0

Install

One line

{{REPO_INSTALL}}

Or run it without installing, with uv:

{{REPO_UVX}}

Python 3.10 or later. The server works with the mcp Python SDK 1.x and 2.x. It reads the API over HTTPS on first use and falls back to the snapshot bundled in the package when the site cannot be reached, so it also works offline.

Configure

Three clients

Claude Desktop

Add to claude_desktop_config.json (Settings, Developer, Edit Config):

{
  "mcpServers": {
    "leadgreen": { "command": "leadgreen-mcp" }
  }
}

Claude Code

claude mcp add leadgreen -- leadgreen-mcp

Cursor

Add the same block to .cursor/mcp.json in the project, or to the global file from Cursor Settings, MCP.

If you run it with uv rather than installing it, use "command": "uvx", "args": ["--from", "{{WHEEL_URL}}", "leadgreen-mcp"] instead.

Tools

Eight tools, one resource

What the server exposes, and a prompt that would call it
ToolAnswersTry asking
list_modelsEvery model on the index, with slugs, ids, parameter counts and measured GPUs"Which models does Lead Green have energy figures for?"
energy_per_million_tokensThe index rows for one model, optionally one GPU"What is the energy per million tokens for Llama 3.1 70B on H100?"
estimateWh and kWh for a token count, with kg CO2e for a country, optionally at a given concurrency"How much energy would 50 million tokens of Qwen 3 32B use on H100s, and what is the carbon in Serbia?"
compare_gpusH100 against B200 for a model, with the ratio"How much does B200 save over H100 for DeepSeek V3.1?"
concurrency_curveEnergy per token at every measured concurrency"Show me how energy per token changes with load for Qwen 3 8B on B200"
grid_intensityAnnual average gCO2e per kWh for a country or World"What is the grid carbon intensity of the Philippines?"
gpu_hardwareMax TDP, memory and MIG profiles"What MIG slices can an H200 be split into?"
sourcesEvery source, version, retrieval date, licence and endpoint"Where do these numbers come from?"

The resource leadgreen://manifest returns the same manifest as a document. Every tool response carries a caveat field; a well-behaved assistant repeats it.

Worked example

Fifty million tokens in Serbia

The estimate tool for {{REF_MODEL}} on H100, 50,000,000 output tokens, country Serbia, uses the index's best H100 row ({{REF_WH_2}} Wh/M, the API's two-decimal value) and Ember's {{EMBER_YEAR}} figure for Serbia ({{SRB_G}} gCO2e per kWh):

  • Energy: {{REF_WH_2}} Wh/M × 50 M = {{EST_50M_WH}} Wh, or {{EST_50M_KWH}} kWh.
  • Carbon: {{EST_50M_KWH}} kWh × {{SRB_G}} g ÷ 1,000 = {{EST_50M_KG_SRB}} kg CO2e.

Pass running_batch (requests_in_flight is still accepted as an alias) and the tool switches from the best row to the measured configuration nearest that running batch, which for a lightly loaded server can multiply the answer several times. That is the honest number for most enterprise deployments.
