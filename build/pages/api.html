Data API

Every table, as JSON

The index is published as static JSON files under /api/v1/. No key, no tracking, no rate limit beyond what a static host imposes. Fetch them from a browser, a spreadsheet, a notebook or a build pipeline. Version 1 only ever adds fields; it never renames or removes them.

Example

Fetch the index and price it on your grid

Two requests, one multiplication. Energy per million tokens times the grid's grams per kWh, divided by 1,000, is kilograms of CO2e per billion tokens.

curl -s {{SITE}}/api/v1/index.json | jq '.rows[] | select(.slug == "{{REF_SLUG}}")'
curl -s {{SITE}}/api/v1/grid.json  | jq '.areas[] | select(.iso3 == "SRB")'

The first returns the reference model's rows (one per GPU); the second returns Serbia at {{SRB_G}} gCO2e per kWh. {{REF_WH_1}} × {{SRB_G}} ÷ 1,000 = {{REF_KG_SRB}} kg CO2e per billion output tokens on the H100 row.

From a browser

CORS is open

The files are served by GitHub Pages, which sends access-control-allow-origin: *, so a page on any origin can fetch them directly.

const r = await fetch("{{SITE}}/api/v1/index.json");
const { rows } = await r.json();
const best = rows[0];   // sorted ascending by Wh per million output tokens
console.log(best.model, best.gpu, best.wh_per_million_output_tokens);

Fields

What the columns mean

index.json rows and models/<slug>.json configurations
FieldMeaning
wh_per_million_output_tokensGPU energy per million output tokens, watt-hours. joules_per_output_token × 1,000,000 ÷ 3,600.
joules_per_output_tokenThe source's figure: GPU energy over the steady-state window divided by the output tokens generated in that window (the benchmark's steady_state_energy_per_token). Prompt processing is included. The source's energy per request is this figure multiplied by the average output length, not a separate measurement.
median_itl_msMedian inter-token latency in milliseconds at that configuration. Index rows are the lowest-energy configuration whose median does not exceed itl_deadline_ms ({{ITL}} ms, the leaderboard's default).
avg_running_batchThe average number of requests the server was decoding at once over the steady-state window (vLLM's num_requests_running). Queued requests are not counted, and the benchmark keeps a queue at all times. max_num_seqs is the configured cap.
avg_requests_in_flightThe same value as avg_running_batch under its first name, kept in v1 so nothing breaks and removed at v2. Despite the name it is the running batch, not the requests a client has outstanding.
gpu_power_watts_totalAverage power drawn, summed across every GPU in the configuration.
tokens_per_secondOutput throughput of the whole configuration.
num_gpus, tensor_parallel, data_parallel, expert_parallelHow many cards and how the model is split across them.
params_b, active_params_b, precisionTotal and activated parameters in billions (they differ for mixture-of-experts models) and the weight precision.
g_co2e_per_kwhGrid emissions intensity of total generation, annual average, from Ember. The year is in the document.
boundarygpu_only: the figures cover GPU energy and nothing else. Host, network, storage, cooling and idle time are outside it. To reach the facility meter, multiply by a system-to-GPU power ratio and the site's PUE (see the index method).
caveatCarried on every document that has index rows. Please carry it into whatever you build.

Versioning and licence

Additive only

Version 1. Fields are added, never renamed or removed. A new source or a re-measurement changes values and the updated date, and the change is recorded on the index's change list. A breaking change would ship as /api/v2/ with v1 left in place.

Licence. The compilation, the derived figures and the site text are offered under CC BY 4.0: use them, credit Lead Green and the underlying source. Each source keeps its own licence, stated per source in manifest.json with the evidence. ML.ENERGY: {{MLE_LICENCE_SENTENCE}} Ember's data is CC BY 4.0. AI Energy Score: Apache-2.0 as tagged on the Hugging Face Space; the project states no separate licence for the results file, which is reproduced as facts with attribution. NVIDIA's figures are reproduced as facts with attribution; NVIDIA grants no licence and none is claimed. The Apache License 2.0 text is in LICENSE, and build/data/NOTICE.md records each snapshot's source, retrieval date and terms.
